\section{\src{Alternative models}}\label{sec:alternatives}
\subsection{\src{Logistic regression}}\label{sec:logistic}

\src{To evaluate an alternative to the random forest, we used a logistic regression model to predict whether an IMF lending programme would be interrupted. We chose logistic regression because the output is binary (Hosmer et al., 2013, p. 1; James et al., 2013, pp. 130–131). It provides a relatively simple and interpretable benchmark against which the performance of a more complex model can be analysed.}

\src{The model was trained on the same 13 inputs as the random forest, covering deal structure, conditionality, track record and macroeconomic conditions. These include economic growth, inflation, whether an arrangement is extended or concessional, and the number of prior actions required before approval. The model estimates the probability of an interruption, which is converted into a binary prediction using a threshold of 0.50 (James et al., 2013, p. 146). It was not tuned, while the random forest was tuned and its threshold searched out of fold. The same training and test sets were used for both models, allowing a direct comparison.}

\src{On the test set of 28 programmes, logistic regression at threshold 0.50 achieved an accuracy of 0.536, a balanced accuracy of 0.570 and an AUC of 0.684, against 0.500, 0.508 and 0.586 for the random forest at its selected threshold of 0.51. At the same 0.50 threshold, however, the forest reaches 0.571 and 0.567, so the two models differ mainly in AUC, which does not depend on the threshold (Fawcett, 2006): logistic regression ranks interrupted programmes above completed ones more consistently. With 28 test programmes, even this gap should be read cautiously, and both results show that predicting interruptions remains difficult. Table~\ref{tab:model-comparison} in Section~\ref{sec:comparison} lists all models side by side.}

\src{A key advantage of logistic regression is its interpretability. Its coefficients indicate how each input is associated with the log-odds of interruption, holding the other inputs constant (Hosmer et al., 2013, pp. 49–52; see Figure~\ref{fig:logit-coefficients}). The largest coefficients are on the two binary facility indicators, extended (−4.18, \emph{p} = 0.004) and concessional (2.31, \emph{p} = 0.087), of which only the former is statistically significant at the 5\% level. These two inputs are strongly correlated in the training data (\emph{r} = 0.81). As a result, the model splits their joint association into opposite signs and estimates both with large standard errors, so their individual coefficients should not be read in isolation (James et al., 2013, pp. 99–102). The absence of a track record also has a sizeable positive coefficient (1.31), but it is imprecisely estimated (\emph{p} = 0.231). More generally, these associations are not causal, and coefficient magnitudes are not directly comparable because the inputs are measured on different scales (Hosmer et al., 2013, pp. 62–64).}

\src{The random forest, in contrast, can capture non-linear relationships and interactions between variables (Breiman, 2001a [p. ?]), at the cost of interpretability (Breiman, 2001b [p. ?]; James et al., 2013, pp. 24–26). Logistic regression imposes a simpler functional form and provides a more transparent account of the relationships it represents.}

\src{Overall, logistic regression matched the random forest on balanced accuracy at the common 0.50 threshold and ranked programmes better, while offering greater interpretability. With only 28 test programmes, the differences should be interpreted cautiously. The comparison is consistent with evidence that a more complex model does not necessarily produce better predictions (Christodoulou et al., 2019 [p. ?]; Couronné et al., 2018 [p. ?]), and that interpretability remains an important consideration when evaluating models for financial decision-making (Rudin, 2019 [p. ?]).}
